Guess My Cheese (Part 1)

/ 01

The Challenge

A cryptography challenge focused on decrypting a secret cheese password. The interface provides a netcat connection with two operations: (g)uess or (e)ncrypt.

/ 02

Identification

The hint explicitly mentioned linear equations and an "affinity" for them—a textbook indicator of the Affine Cipher.

Encryption: E(x) = (ax + b) mod 26
Decryption: D(x) = a⁻¹(x - b) mod 26
/ 03

Strategy & Logic

Using a Known Plaintext Attack, I fed the oracle the word CHEDDAR to extract the keys.

/ 04

Cracking the Keys

By mapping A=0, we isolate the variables:

1. Finding b:
   Plaintext A (0) -> Ciphertext H (7)
   E(0) = (a * 0 + b) = 7  => b = 7

2. Finding a:
   Plaintext C (2) -> Ciphertext N (13)
   2a + 7 = 13 mod 26 
   2a = 6  => a = 3

3. Finding Inverse:
   3 * 9 = 27 ≡ 1 mod 26 => a_inv = 9
